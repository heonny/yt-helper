YouTube Music 연결

  1. Chrome에서 music.youtube.com에 로그인합니다.
  2. 개발자도구를 엽니다. Mac은 Cmd+Opt+I, Windows는 F12입니다. Network 탭 필터에 youtubei/v1/browse를 입력합니다.
  3. YouTube Music 화면에서 "보관함"을 클릭하면 POST 요청이 나타납니다.
  4. 그 요청을 우클릭하고 Copy → Copy as cURL을 고릅니다. Windows에서는 cmd와 bash 중 어느 쪽을 골라도 됩니다.
  5. 아래 칸에 붙여넣고 연결을 누릅니다. Request Headers 원문을 붙여넣어도 됩니다.
  • 붙여넣은 내용은 이 컴퓨터에서 실행 중인 yt-helper로만 전달되고, yt-helper는 이 쿠키로 YouTube Music에만 요청합니다. 다른 서버로는 보내지 않습니다.
  • 쿠키는 ~/.config/yt-helper/browser.json에 저장되므로 브라우저나 서버를 꺼도 연결이 유지됩니다. Windows에서는 %USERPROFILE%\.config\yt-helper\browser.json입니다. macOS와 Linux에서는 권한 600으로 내 계정만 읽을 수 있고, Windows에서는 사용자 폴더의 기본 접근 권한을 따릅니다.
  • 인증 해제는 이 파일을 지웁니다. 쿠키 자체를 무효로 하려면 YouTube에서 로그아웃하세요.
